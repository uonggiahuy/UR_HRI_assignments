usage: verify_navigation.py [-h] --output OUTPUT --registration REGISTRATION
                            [--goals GOALS] [--goal-timeout GOAL_TIMEOUT]

M4.3 simulator-only evidence capture: one real A-to-B Nav2 goal. Requires a
safely undocked, localized Standard robot in the real saved warehouse map,
with Nav2 active. This script DOES execute simulation navigation actions. It
never publishes teleop velocity, fake TF or robot poses. Use only in
simulation.

options:
  -h, --help            show this help message and exit
  --output OUTPUT
  --registration REGISTRATION
                        Reviewed world-to-map landmark registration JSON; no
                        identity assumption
  --goals GOALS         JSON list with exactly one named destination B in
                        validated map space
  --goal-timeout GOAL_TIMEOUT
